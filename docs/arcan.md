# Arcan Player - Manual y Documentacion

## Que es Arcan Player

Arcan Player es un reproductor multimedia moderno y multiplataforma para audio y video con interfaz moderna, ecualizador, listas de reproduccion y mas.

## Plataformas soportadas

- Windows (.exe)
- Mac (.dmg)
- Linux (.AppImage)

## Funciones principales

### Reproduccion de audio
- Formatos soportados: MP3, WAV, FLAC, AAC, OGG, M4A
- Ecualizador con presets personalizables
- Visualizacion de audio en tiempo real
- Modo repeat y aleatorio

### Reproduccion de video
- Formatos soportados: MP4, MKV, AVI, MOV, WebM
- Pantalla completa
- Controles de velocidad
- Subtitulos integrados

### Listas de reproduccion
- Crear listas personalizadas
- Importar/Exportar listas
- Ordenar por nombre, duracion, artista
- Buscar en listas

### Interfaz
- Tema oscuro moderno
- Modo compacto
- Mini reproductor
- Controles flotantes

### Configuracion
- Tema personalizable
- Atajos de teclado
- Carpeta de inicio
- Idioma
