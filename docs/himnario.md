# Himnario Adventista PRO - Manual y Documentacion

## Que es Himnario Adventista PRO

Himnario Adventista PRO es una aplicacion de escritorio para Windows, Mac y Linux que contiene el himnario completo de la Iglesia Adventista del Septimo Dia. Permite buscar himnos, ver acordes, letras, y usar funciones de proyeccion para iglesias.

## Plataformas soportadas

- Windows (.exe)
- Mac (.dmg)
- Linux (.AppImage)

## Funciones principales

### Busqueda de himnos
- Busqueda por numero de himno
- Busqueda por titulo
- Busqueda por letra (texto completo)
- Busqueda por categoria

### Reproduccion de audio
- Instrumental de cada himno
- Coro con letra sincronizada
- Control de volumen
- Reproduccion automatica

### Proyeccion para iglesias
- Modo proyeccion con letra grande
- Transicion automatica entre estrofas
- Control remoto desde otro dispositivo

### Biblia integrada
- Version Reina-Valera 1960
- Busqueda de versiculos
- Navegacion por libros, capitulos y versiculos

### Acordes
- Acordes para guitarra y piano
- Transposicion de acordes
- Modo simplificado para principiantes

### Configuracion
- Tema claro y oscuro
- Tamano de fuente ajustable
- Idioma (espanol, ingles, portugues)
- Guardar preferencias

## Como descargar e instalar

1. Ir a la pagina del proyecto
2. Descargar el instalador para tu sistema operativo
3. Ejecutar el instalador
4. Seguir las instrucciones en pantalla

## Solucion de problemas

### La aplicacion no abre
- Verificar que el sistema operativo sea compatible
- Reinstalar la aplicacion
- Verificar permisos de administrador

### No hay audio
- Verificar que los altavoces esten conectados
- Revisar el volumen del sistema
- Reinstalar la aplicacion

### Error de actualizacion
- Descargar la version mas reciente desde la página oficial
- Desinstalar la version anterior primero
