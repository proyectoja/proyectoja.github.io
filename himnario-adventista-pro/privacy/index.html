Política de privacidad

Esta política explica qué información trata Himnario Adventista PRO al visitar el sitio, comprar una suscripción y activar la aplicación.

Última actualización 20 de noviembre de 2026

1. Responsable y alcance

El administrador del proyecto Himnario Adventista PRO gestiona este sitio y atiende consultas de privacidad a través de la página de soporte. Esta política cubre el sitio de suscripción y la información necesaria para activar el servicio; PayPal, Paddle y otros terceros aplican sus propios avisos.

2. Datos que proporcionas

Después del checkout, la página solicita un nombre de usuario y un correo electrónico para vincular el pago con tu cuenta de la aplicación. El proveedor de pago puede proporcionar el correo asociado al pago, que se muestra como sugerencia; puedes corregirlo antes de enviar el formulario.

3. Datos de pago y proveedores

PayPal o Paddle procesa la transacción y los datos de pago bajo sus propios términos y políticas. El sitio no recibe ni almacena el número completo de tu tarjeta. Para gestionar y verificar la activación, la página transmite al servicio de verificación del proyecto el identificador de suscripción o transacción, el proveedor de pago, el nombre de usuario y el correo que proporcionaste.

4. Almacenamiento local

La página utiliza el almacenamiento local de tu navegador para recordar el nombre de usuario, correo, referencia del pago y código de activación, y para recuperar el código cuando vuelvas a abrir la página desde el mismo navegador. Puedes borrar esos datos desde la configuración del navegador; al hacerlo quizá debas volver a introducir la información o recuperar el código por otro medio.

5. Uso de la información

Los datos se usan para verificar el pago, vincular la suscripción con la cuenta de la aplicación, habilitar las funciones contratadas, responder consultas, prevenir errores o fraude y cumplir obligaciones legales. La aplicación puede guardar en el dispositivo las preferencias y recursos locales que utilices en sus funciones.

6. Servicios de terceros y datos técnicos

El sitio integra los SDK de PayPal y Paddle, fuentes tipográficas y recursos externos, alojamiento web y un servicio de verificación de suscripciones. Esos proveedores pueden recibir datos técnicos como dirección IP, identificadores del navegador, solicitudes y registros de seguridad. Consulta sus avisos de privacidad para conocer sus prácticas. No se envían datos de tarjeta a soporte por correo.

7. Conservación

Los datos del navegador permanecen hasta que los elimines o limpies el almacenamiento local. El proveedor de pago y el servicio de verificación pueden conservar registros de transacciones durante el tiempo necesario para administrar suscripciones, atender disputas y cumplir obligaciones contables o legales.

8. Seguridad y derechos

Se aplican medidas razonables para proteger la información, aunque ningún dispositivo o transmisión puede garantizar seguridad absoluta. Según la legislación aplicable, puedes tener derecho a solicitar acceso, corrección o eliminación de ciertos datos. Consulta soporte para realizar una solicitud; algunos registros deben conservarse por obligaciones legales o de pago.

9. Menores de edad y cambios

Las compras deben realizarse por una persona legalmente autorizada. Si un padre, madre o tutor cree que un menor proporcionó información personal, puede solicitar ayuda mediante soporte. Esta política puede cambiar; publicaremos aquí la versión vigente y su fecha.

10. Contacto

Para preguntas o solicitudes de privacidad, visita la página de Soporte. Para datos de pago, también puedes contactar al proveedor que aparece en tu recibo.
